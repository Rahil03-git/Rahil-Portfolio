Kazi Shibli Zaman Rahil | Portfolio
===================================

Open index.html in your browser to view the site.

Folder layout
  index.html   page structure and all JavaScript
  style.css    all styling (colours, fonts, layout)
  images/      every image used by the site
  Rahil_CV.pdf and Rahil_Resume.pdf   file behind the "CV & Resume" buttons

Quick edits
  Accent colour : top of style.css, change --ac (and --actx for small text).
  Name font     : style.css, change --serif.
  Photos        : replace images/1st.jpg and images/2nd.jpg (keep the names).
  Project covers: images/project-*.svg are generated artwork. Replace with a real
                  screenshot, then change the img path in index.html (search for
                  "images/project-") e.g. img:"images/project-1.png".
  Gallery       : images/gallery-1.jpg ... gallery-7.jpg, captions are in index.html.
  CV & Resume   : replace the PDFs, keep the same file name.

Publishing: upload this whole folder to Netlify, Vercel or GitHub Pages
(index.html must stay at the top level of the folder).
